# Cyclone Bazar

A mobile-first dropshipping e-commerce platform built for the Bangladesh market.

## Current Status
- Laravel 11 + Livewire 3 structure (code snippets)
- Cash on Delivery (COD) payment gateway
- 4-level Bangladesh address system (Division → District → Upazila → Area)
- Atomic order system with inventory locking
- Basic Admin Panel (Products, Orders, Banners, Settings)
